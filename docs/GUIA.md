## Comandos que mas uso

Para ver el estado del proyecto uso `git status`.

```bash
git checkout -b menu
git git merge menu
git branch -d menu
```
| Comando | Que hace |
|---------|----------|
| git checkout -b menu | Crear la rama menu y cambiarte a ella |
| git merge menu | Unir la rama menu a main. |
| git branch -d | Borrar la rama |
